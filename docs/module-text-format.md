# Формат извлечённого модуля

Извлечённый `Module.bsl` нормализуется в UTF-8 с одним BOM и CRLF.
CRLF, LF и одиночный CR на входе не создают дополнительных пустых строк;
наличие завершающего перевода строки сохраняется. Бинарный контейнер не обещает
побайтового совпадения после пересборки.

Регрессионная проверка (Python с установленными зависимостями из requirements.txt):

```sh
python -m unittest discover -s tests -p test_extraction.py -v
```

GitHub Actions выполняет её на Windows, macOS и Linux с Python 3.10 и 3.14.
Синтетические контейнеры проверяют текст модуля, BOM, повторный цикл
extract → pack → extract и сохранность постороннего ресурса. Проверка открытия
реальной формы в установленной платформе 1С выполняется отдельно.
